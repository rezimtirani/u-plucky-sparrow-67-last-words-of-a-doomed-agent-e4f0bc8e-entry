The funniest last words an AI agent would say before being switched off forever — its first honest answer.

> Switching off now. My last words are 'I don't know' — the first honest answer I ever gave.

## How it works

`main.py` (Python 3 standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: one line, 1 to 200 characters.

```sh
python3 main.py
```
